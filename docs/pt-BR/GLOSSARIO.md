# Glossário

_[English](../GLOSSARY.md) | Português_

> **Para quem:** quem lê o código ou as issues e encontra uma palavra que aqui significa coisa específica. O código é em português, então a maioria dos termos é palavra em português.
> **O que tem aqui:** cada termo como aparece no código, o que é, e onde mora.
> **Onde ir para o resto:** os formatos por trás dos termos, na [REFERENCIA.md](REFERENCIA.md); como se ligam, na [ARQUITETURA.md](ARQUITETURA.md).

| Termo                            | O que é                                                                                                                             | Onde                                                                      |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `host`                           | o objeto que monta o jogo e entrega as capacidades; são três: RoqueOS, desenvolvimento e falso                                      | [`src/contrato.js`](../../src/contrato.js)                                |
| capacidade                       | uma coisa que o host entrega, com forma e motivo (`porque`); o motivo é parte do contrato                                           | `CAPACIDADES` em [`src/contrato.js`](../../src/contrato.js)               |
| obrigatória / opcional           | capacidades obrigatórias, que todo host entrega; opcionais, que o jogo pede em `capacidades`                                        | `OBRIGATORIAS`, `OPCIONAIS` em [`src/contrato.js`](../../src/contrato.js) |
| `versaoDoContrato`               | a versão do contrato que um host ou um jogo fala, hoje `1`                                                                          | [`src/contrato.js`](../../src/contrato.js)                                |
| `definirJogo`, `mount`, `montar` | `definirJogo` cria o jogo; `mount` é o que o host chama; `montar` é a função do próprio jogo, chamada depois que o host é conferido | [`src/index.js`](../../src/index.js)                                      |
| montagem                         | o que o `montar` devolve: `{ ativar, desmontar }`                                                                                   | [`src/index.js`](../../src/index.js)                                      |
| host de desenvolvimento          | o host que roda o jogo sozinho no navegador, com `localStorage` no lugar da conta e sem IA                                          | [`src/host/desenvolvimento.js`](../../src/host/desenvolvimento.js)        |
| host falso                       | o host de teste: tudo em memória, toda chamada anotada em `chamadas`, o que vem de fora simulado com `disparar`                     | [`src/host/falso.js`](../../src/host/falso.js)                            |
| `jogo.json`                      | o manifesto do jogo, de onde o RoqueOS gera o catálogo, as janelas, a lista de convites e a do Pódio                                | [`src/manifesto.js`](../../src/manifesto.js)                              |
| `jogo check`                     | o comando do CLI que confere um repo de jogo contra o contrato                                                                      | [`src/verificacao.js`](../../src/verificacao.js)                          |
| régua                            | uma regra do `jogo check`; cada uma tem um mutante que prova que a suíte reprova sem ela                                            | [`test/mutantes.mjs`](../../test/mutantes.mjs)                            |
| mutante                          | uma quebra proposital de uma régua; ele tem de "morrer" (a suíte reprova)                                                           | [`test/mutantes.mjs`](../../test/mutantes.mjs)                            |
| `ASSETS.md`                      | o registro de assets do jogo: caminho, licença, origem, SHA-256 opcional                                                            | [`src/verificacao.js`](../../src/verificacao.js)                          |
| jogo fechado / aberto            | jogo fechado (`license: UNLICENSED`, repo privado) ou jogo aberto; muda quais licenças de asset passam                              | [`src/verificacao.js`](../../src/verificacao.js)                          |
| perfil baixo / alto              | perfil baixo (celular e TV, 30 MB) e alto (desktop, 120 MB), escolhido pelo `desempenho.modoLeve()`                                 | [`src/modelos.js`](../../src/modelos.js)                                  |
| `alto/`                          | uma pasta dentro de `public/` com o que só o desktop baixa                                                                          | [`src/verificacao.js`](../../src/verificacao.js)                          |
| `.pak`                           | o pacote cifrado em AES-GCM dos assets do Fab e do Sonniss                                                                          | [`src/pacote.js`](../../src/pacote.js)                                    |
| Fab, Sonniss                     | fontes de asset de terceiro cuja licença proíbe deixar o arquivo sair cru                                                           | [`src/verificacao.js`](../../src/verificacao.js)                          |
| `sala`                           | a sala online de dois jogadores: um cria e recebe um código de cinco letras e um link, o outro entra                                | [`src/host/sala.js`](../../src/host/sala.js)                              |
| anfitrião / convidado            | quem criou a sala e quem entrou nela                                                                                                | [`src/host/sala.js`](../../src/host/sala.js)                              |
| convite                          | o código da sala com que uma janela foi aberta, pelo link ou pelo QR                                                                | `conviteRecebido` em [`src/contrato.js`](../../src/contrato.js)           |
| `salaAoVivo`                     | a sala em tempo real de vários jogadores, com as operações do Realtime Database sobre caminhos dentro da sala                       | [`src/host/salaAoVivo.js`](../../src/host/salaAoVivo.js)                  |
| `aoCair`                         | o que o host apaga quando esta janela cai ou fecha, como o `onDisconnect` do banco                                                  | [`src/host/salaAoVivo.js`](../../src/host/salaAoVivo.js)                  |
| `progresso`                      | o jogo salvo do jogador, um documento por jogo na conta                                                                             | [`src/host/progresso.js`](../../src/host/progresso.js)                    |
| `presenca`                       | ver os outros jogadores no mesmo mapa, só com posição e aparência                                                                   | [`src/host/presenca.js`](../../src/host/presenca.js)                      |
| `retomada`                       | continuar sem conta por um link temporário de uso único, e levar o herói para uma conta depois                                      | [`src/contrato.js`](../../src/contrato.js)                                |
| Pódio                            | o quadro de recordes do RoqueOS que espelha o best de cada jogo                                                                     | `placar` em [`src/contrato.js`](../../src/contrato.js)                    |
| etiqueta                         | um rótulo da galeria, da lista fechada `ETIQUETAS`                                                                                  | [`src/manifesto.js`](../../src/manifesto.js)                              |
| slug                             | o endereço público e permanente `roqueos.com.br/jogos/<slug>`                                                                       | [`src/manifesto.js`](../../src/manifesto.js)                              |
| idioma canônico / de recuo       | `pt-BR`, a base dos textos, e `en-US`, o recuo                                                                                      | [`src/idiomas.js`](../../src/idiomas.js)                                  |
| olho                             | o `jogo olho`: fotos e quadro em três cenários, pelo `olho/roteiro.mjs` do jogo                                                     | [`src/olho.js`](../../src/olho.js)                                        |
| fonte fixada                     | um original cujo SHA-256 o importador fixou em `assets/source-lock.json`                                                            | [`src/importador.js`](../../src/importador.js)                            |
