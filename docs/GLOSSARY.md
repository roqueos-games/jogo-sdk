# Glossary

_English | [Português](pt-BR/GLOSSARIO.md)_

> **Who it is for:** whoever reads the code or the issues and meets a word that means something specific here. The code is in Portuguese, so most terms are Portuguese words.
> **What is here:** each term as it appears in the code, what it is, and where it lives.
> **Where to go for the rest:** the formats behind the terms, in [REFERENCE.md](REFERENCE.md); how they fit, in [ARCHITECTURE.md](ARCHITECTURE.md).

| Term                             | What it is                                                                                                                           | Where                                                                  |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------- |
| `host`                           | the object that mounts the game and hands it the capabilities; there are three: RoqueOS, development and fake                        | [`src/contrato.js`](../src/contrato.js)                                |
| capacidade (capability)          | one thing the host provides, with a shape and a reason (`porque`); the reason is part of the contract                                | `CAPACIDADES` in [`src/contrato.js`](../src/contrato.js)               |
| obrigatória / opcional           | mandatory capabilities every host provides; optional ones the game asks for in `capacidades`                                         | `OBRIGATORIAS`, `OPCIONAIS` in [`src/contrato.js`](../src/contrato.js) |
| `versaoDoContrato`               | the contract version a host or a game speaks, today `1`                                                                              | [`src/contrato.js`](../src/contrato.js)                                |
| `definirJogo`, `mount`, `montar` | `definirJogo` builds the game; `mount` is what the host calls; `montar` is the game's own function, called after the host is checked | [`src/index.js`](../src/index.js)                                      |
| montagem                         | what `montar` returns: `{ ativar, desmontar }`                                                                                       | [`src/index.js`](../src/index.js)                                      |
| host de desenvolvimento          | the host that runs a game alone in the browser, with `localStorage` instead of the account and no AI                                 | [`src/host/desenvolvimento.js`](../src/host/desenvolvimento.js)        |
| host falso                       | the test host: everything in memory, every call recorded in `chamadas`, outside events simulated with `disparar`                     | [`src/host/falso.js`](../src/host/falso.js)                            |
| `jogo.json`                      | the game's manifest, from which RoqueOS builds its catalog, windows, invite list and Podium list                                     | [`src/manifesto.js`](../src/manifesto.js)                              |
| `jogo check`                     | the CLI command that checks a game repo against the contract                                                                         | [`src/verificacao.js`](../src/verificacao.js)                          |
| régua (rule)                     | one rule of `jogo check`; each has a mutant that proves the suite fails without it                                                   | [`test/mutantes.mjs`](../test/mutantes.mjs)                            |
| mutante                          | a deliberate break of a rule; it must "die" (the suite fails)                                                                        | [`test/mutantes.mjs`](../test/mutantes.mjs)                            |
| `ASSETS.md`                      | the game's asset ledger: path, license, source, optional SHA-256                                                                     | [`src/verificacao.js`](../src/verificacao.js)                          |
| jogo fechado / aberto            | closed game (`license: UNLICENSED`, private repo) or open game; changes which asset licenses pass                                    | [`src/verificacao.js`](../src/verificacao.js)                          |
| perfil baixo / alto              | low profile (phone and TV, 30 MB) and high profile (desktop, 120 MB), chosen from `desempenho.modoLeve()`                            | [`src/modelos.js`](../src/modelos.js)                                  |
| `alto/`                          | a folder inside `public/` with what only the desktop downloads                                                                       | [`src/verificacao.js`](../src/verificacao.js)                          |
| `.pak`                           | the AES-GCM encrypted pack for Fab and Sonniss assets                                                                                | [`src/pacote.js`](../src/pacote.js)                                    |
| Fab, Sonniss                     | third-party asset sources whose licenses forbid letting the file out raw                                                             | [`src/verificacao.js`](../src/verificacao.js)                          |
| `sala`                           | the two-player online room: one creates and gets a five-letter code and a link, the other joins                                      | [`src/host/sala.js`](../src/host/sala.js)                              |
| anfitrião / convidado            | the player who created the room and the one who joined                                                                               | [`src/host/sala.js`](../src/host/sala.js)                              |
| convite                          | the room code a window was opened with, by link or QR                                                                                | `conviteRecebido` in [`src/contrato.js`](../src/contrato.js)           |
| `salaAoVivo`                     | the real-time room for many players, with Realtime Database operations on paths inside the room                                      | [`src/host/salaAoVivo.js`](../src/host/salaAoVivo.js)                  |
| `aoCair`                         | what the host deletes when this window drops or closes, like the database's `onDisconnect`                                           | [`src/host/salaAoVivo.js`](../src/host/salaAoVivo.js)                  |
| `progresso`                      | the player's saved game, one document per game on the account                                                                        | [`src/host/progresso.js`](../src/host/progresso.js)                    |
| `presenca`                       | seeing the other players on the same map, with position and appearance only                                                          | [`src/host/presenca.js`](../src/host/presenca.js)                      |
| `retomada`                       | continuing without an account through a temporary single-use link, and taking the hero to an account later                           | [`src/contrato.js`](../src/contrato.js)                                |
| Pódio (Podium)                   | the RoqueOS high-score board that mirrors each game's best                                                                           | `placar` in [`src/contrato.js`](../src/contrato.js)                    |
| etiqueta (tag)                   | a gallery label from the closed `ETIQUETAS` list                                                                                     | [`src/manifesto.js`](../src/manifesto.js)                              |
| slug                             | the public, permanent address `roqueos.com.br/jogos/<slug>`                                                                          | [`src/manifesto.js`](../src/manifesto.js)                              |
| idioma canônico / de recuo       | `pt-BR`, the base of the texts, and `en-US`, the fallback                                                                            | [`src/idiomas.js`](../src/idiomas.js)                                  |
| olho                             | `jogo olho`: screenshots and frame timing in three scenarios, through the game's `olho/roteiro.mjs`                                  | [`src/olho.js`](../src/olho.js)                                        |
| fonte fixada                     | an original whose SHA-256 the importer pinned in `assets/source-lock.json`                                                           | [`src/importador.js`](../src/importador.js)                            |
